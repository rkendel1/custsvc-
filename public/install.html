Install steps

  1. Copy the tenant-scoped script below.
  2. Paste it right before the closing body tag on your site page.
  3. Publish and refresh. The KnowledgeOS assistant will load with your tenant bundle.
  4. For custom UI behavior, pass optional data attributes after initial install.
If your tenant bundle does not exist yet, run onboarding and deploy once before installation.
